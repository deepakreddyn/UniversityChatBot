# 🎓 University Chatbot

## 📌 Project Overview
University Chatbot is an **AI-driven chatbot** designed to provide instant information about **university courses, fees, admissions, and placements**. This project helps prospective students and parents easily access relevant university details.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Database:** JDBC (Java Database Connectivity), MySQL/SQLite
- **AI & NLP:** Natural Language Processing (NLP)
- **Frameworks:** Java Swing (for GUI, if applicable)

## 📂 Features Implemented
- **Automated Q&A:** Instantly answers common university-related queries.
- **Course & Fee Details:** Retrieves course offerings and fee structures.
- **Placement Information:** Provides past placement statistics and top recruiters.
- **User Interaction Logging:** Stores chat history for future improvements.

## 🚀 Installation & Usage
### 🔹 Clone the Repository
```bash
git clone https://github.com/deepakreddyn/UniversityChatBot.git
cd UniversityChatBot
```
### 🔹 Install Dependencies
Ensure Java and JDBC drivers are installed on your system.

### 🔹 Compile and Run the Application
```bash
javac Chatbot.java
java Chatbot
```
